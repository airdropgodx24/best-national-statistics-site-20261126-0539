StatAtlas is a national statistics explorer: population, economy, health, education and connectivity for eight countries (Nigeria, United States, United Kingdom, India, Japan, Brazil, Germany, South Africa), every figure shown with its source and year. It has six sections reached from the nav — Overview, Population, Economy, Health & Education, Compare, and Data & Sources — with trend charts since 2000 (line or bars, optional second-country overlay), age and sector breakdowns, country rankings, a side-by-side comparison table, and a searchable, sortable data table. The site is plain static files under `app/` with no build step and no network requests; all charts are hand-rolled SVG drawn by its own code.

## Run it

```sh
node serve.ts          # serves app/ at http://localhost:8080
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts   # writes out/dossier.json
```
